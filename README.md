# 推し活ダッシュボード

Pythonの標準ライブラリ `http.server` を使用して作成した、
推し活向けのWebダッシュボードです。

天気・ニュース・名言をトップページに表示し、
お気に入りの作品や人物などをJSONファイルで管理できます。


## 主な機能

### ダッシュボード

- 今日の天気を表示
- ニュースを表示
- 名言をランダムに1件表示

天気情報は、つくみ島の天気予報APIから取得しています。

### お気に入り管理

- お気に入り一覧表示
- お気に入り追加
- お気に入り編集
- お気に入り削除
- タイトル検索
- ジャンル検索
- タグ検索
- ジャンルによる絞り込み
- タイトル・ジャンルによる並び替え

お気に入りデータは `data/favorites.json` に保存されます。


## お気に入りのデータ形式

お気に入りは、次の形式でJSONファイルに保存します。

```json
{
    "id": 1,
    "title": "ドラえもん",
    "genre": "アニメ",
    "tags": [
        "キャラクター",
        "漫画原作"
    ]
}
